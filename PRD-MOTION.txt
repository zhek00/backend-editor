# Documento de Requisitos do Produto (PRD)
## Motor de Motion Graphics Autônomo — Estilo Editorial Vox / SaaS

---

### 1. Visão Geral e Objetivo
Implementar no **TipLabs** um módulo de **fallback de Motion Graphics** para substituir cenas cujas mídias de acervo foram rejeitadas pelo avaliador JEV.

O motor deve gerar animações 2D no estilo **Editorial / Vox / SaaS Explainer** (fundo creme/off-white com textura de pontos, tipografia serifada/sans-serif híbrida, diagramas vetoriais SVG, cards em squircle e gráficos animados), utilizando **APIs 100% gratuitas (Groq e OpenRouter)** sem custo por cena.

---

### 2. Regra Zero de Arquitetura (CRÍTICO)
* **Preservação do Sistema Existente:** É estritamente proibido alterar, refatorar ou apagar rotas de API, gerenciamento de estado da timeline, banco de dados ou renderização original do TipLabs.
* **Isolamento de Código:** Todo o serviço deve ser criado dentro da pasta `/src/services/motionEngine/`.
* **Substituição Transparente:** O arquivo `.mp4` gerado pelo renderizador local substituirá o caminho da mídia original no JSON da cena, exatamente como faz o acervo.
* **Fallback de Segurança:** Caso ocorra falha de renderização ou timeout, o sistema manterá a mídia original do acervo sem interromper o fluxo do projeto.

---

### 3. Diretrize de Design System (Estilo Vox / SaaS Editorial)

O código HTML5/Canvas/SVG gerado pela LLM DEVE obrigatoriamente seguir estas regras visuais rígidas:

┌────────────────────────────────────────────────────────┐
│ TOP: Tipografia Misturada (Serif + Sans) + Highlights │
├────────────────────────────────────────────────────────┤
│ CENTER: Diagrama 2D / Conexões SVG / Squircle Cards    │
├────────────────────────────────────────────────────────┤
│ BACKGROUND: Off-White (#F7F6F2) + Dot Grid Texture     │
└────────────────────────────────────────────────────────┘


#### A. Paleta de Cores e Fundo
* **Fundo Base:** Off-White aquecido (`#F7F6F2` ou `#F4F3EF`).
* **Textura:** Grid de pontos sutis usando CSS:
  `background-image: radial-gradient(#d1d0c9 1px, transparent 1px); background-size: 24px 24px;`
* **Cores de Acento:** Verde Floresta (`#166534`), Azul Royal (`#2563EB`), Laranja Quente (`#EA580C`) e Preto Grafite (`#1A1A1A`).

#### B. Componentes Visuais (Primitivas do Motion)
1. **Cards (Squircles):** Quadrados com cantos super arredondados (`border-radius: 20px`), fundo branco `#FFFFFF` e sombra suave `box-shadow: 0 12px 32px rgba(0,0,0,0.06)`.
2. **Conectores SVG:** Linhas curvas suaves (`path` SVG com `cubic-bezier`) conectando os cards. As linhas devem ser animadas usando `stroke-dashoffset`.
3. **Gráficos Dinâmicos:** Barras verticais que sobem de baixo para cima com `scaleY(0 -> 1)` e setas de tendência vetoriais apontando para cima.
4. **Tipografia Híbrida:** 
   * Texto normal em Sans-Serif clean (Inter / SF Pro).
   * Palavra de destaque/ênfase em **Serif elegante com cor destacada** (ex: Georgia / Playfair Display).

#### C. Física e Animação (Spring Engine)
* **Proibido:** Animações com `linear` ou entradas estáticas.
* **Obrigatório:** Entrada de cards e textos com física de mola (`cubic-bezier(0.34, 1.56, 0.64, 1)` ou GSAP `back.out(1.7)`).
* **Micro-Movimento:** Flutuação suave contínua (`y: -5px` a `5px`) nos cards para manter a tela viva.

6. Pipeline de Renderização Local (Headless Render)
O backend salva o código HTML gerado em um arquivo temporário em ./temp/motion_scene.html.

O Playwright abre a página em segundo plano na resolução exata da cena.

Um loop Node.js executa o render frame a frame:

Invocando window.seekToFrame(frame, totalFrames, 30).

Capturando o buffer da imagem diretamente da VRAM.

Enviando o buffer via pipe direto para o FFMPEG.

O FFMPEG gera o arquivo .mp4 compilado em H.264 e salva na pasta final do projeto.

Os arquivos temporários são deletados.
